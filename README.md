# SARDAR GAMING SPACE

A simple red/black Android dashboard starter project.

## Build APK using GitHub Actions
1. Extract this ZIP on your phone.
2. Upload the **contents** of the extracted folder to your GitHub repository (not the ZIP file itself).
3. Open the repository's **Actions** tab.
4. Select **Build Android APK** and tap **Run workflow** (or wait for the automatic build after upload).
5. When the workflow finishes, open the run and download the `Sardar-Gaming-Space-APK` artifact.
6. Extract the downloaded artifact ZIP; install `app-debug.apk`.

This is a starter project. It opens Android settings and includes a basic multi-touch test. It cannot overclock the phone, change hardware touch limits, unlock FPS, or guarantee lower ping.
